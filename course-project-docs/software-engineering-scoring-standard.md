# 软件工程课程设计评分标准

## 评分维度

### 1. 选题与目标

- 选题具有明确的软件系统目标
- 功能范围适中，能够在课程设计周期内完成
- 题目与课程知识点相关

### 2. 需求分析

- 能够明确用户角色
- 能够给出核心功能需求
- 能够说明非功能需求，如性能、易用性、可维护性

### 3. 系统设计

- 具有清晰的系统架构说明
- 模块划分合理
- 数据流或业务流程表达清楚

### 4. 数据库设计

- 表结构设计规范
- 主键、外键或逻辑关系清晰
- 字段命名统一

### 5. 系统实现

- 核心功能可运行
- 前后端分层清晰
- 代码结构规范

### 6. 测试与总结

- 具备基本测试用例
- 能说明系统功能验证结果
- 能总结项目不足与改进方向

## 教师常见关注点

- 课设功能是否真实完成
- 数据库设计是否合理
- 报告是否与代码实现一致
- 答辩时是否能解释自己的系统设计
